# La Familia Launcher – öffentliche Updates

Dieses Repository enthält ausschließlich die veröffentlichten Windows-Launcher-Versionen (`LaFamiliaLauncher.exe`).

Der Quellcode und die Entwicklung bleiben im privaten Repository. Die EXE wird dort über GitHub Actions erstellt und mit einem eingeschränkten GitHub-Token als Release hier veröffentlicht.

## Download

Sobald das erste Release veröffentlicht wurde: [Neueste Launcher-Version](https://github.com/Overdosxxl/LaFamilia-Launcher-Updates/releases/latest).

Die Updateprüfung des Launchers verwendet die öffentliche GitHub-Releases-API dieses Repositories. Die Installation prüft den von GitHub bereitgestellten SHA-256-Digest.
